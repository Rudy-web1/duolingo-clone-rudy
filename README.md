# 🦉 Duolingo Clone

A full-stack Duolingo-inspired language learning web application built using Next.js, TypeScript, FastAPI, SQLAlchemy, and SQLite.

The application provides a gamified Spanish learning experience with a skill tree, guided learning, interactive lessons, XP, streaks, hearts, leaderboard, achievements, and persistent user progress.

# ✨ Features

### Learning Path

- Unit and skill-based learning path
- Locked and unlocked skills
- Skill completion tracking
- Crown-based progress
- Continue and review functionality
- Visual progress indicators

### Guidebook

Each skill provides a **Learn** option before practice.

The Guidebook contains:

- Skill introduction
- Vocabulary explanations
- Example sentences
- Learning tips
- Text-to-speech pronunciation
- Guided card progression

Learning flow:

```text
Skill
  ↓
📖 Learn
  ↓
Teaching Cards
  ↓
Practice Lesson
  ↓
Feedback
  ↓
XP + Progress
